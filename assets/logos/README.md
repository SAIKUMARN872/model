# Logos

This directory stores branding assets.

## Recommended Files

- logo.svg
- logo.png
- logo-dark.png
- logo-light.png
- favicon.ico

## Example Structure

```text
logos/
├── logo.svg
├── logo.png
├── logo-dark.png
├── logo-light.png
└── favicon.ico
```

## Usage

Example:

```jsx
<img src="/logos/logo.svg" alt="Application Logo" />
```

Keep original logo files in high resolution and use optimized versions for the web.
