# Icons

This directory stores all application icons.

## Supported Formats

- SVG (Recommended)
- PNG
- ICO

## Example Structure

```text
icons/
├── home.svg
├── search.svg
├── settings.svg
├── user.svg
└── notification.svg
```

## Usage

Icons can be referenced directly from the public directory.

Example:

```jsx
<img src="/icons/home.svg" alt="Home" />
```

Keep icon naming lowercase and descriptive.
