# Images

This directory contains application images.

## Supported Formats

- PNG
- JPG
- JPEG
- WEBP
- SVG
- GIF

## Example Structure

```text
images/
├── hero.png
├── dashboard.png
├── avatar.jpg
├── empty-state.svg
└── banner.webp
```

## Usage

Images can be accessed directly.

Example:

```jsx
<img src="/images/hero.png" alt="Hero" />
```

Optimize images before adding them to the project to improve performance.
